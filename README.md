# 🛒 বাজার দর | BazarDor

**BazarDor** is a modern, responsive web application that helps users explore market prices and browse product categories through a simple, user-friendly interface. Built with modern web technologies, it aims to make market information more accessible.

## 🛠️ Technologies Used

* **Next.js** — React framework for building the web application.
* **React** — Component-based user interface development.
* **Tailwind CSS** — Responsive styling and modern UI design.
* **Better Auth** — User authentication and session management.
* **MongoDB** — Database integration.
* **JavaScript** — Application logic.
* **Lucide React** — Icons and interface elements.
* **React Hot Toast** — User notifications.

## ✨ Key Features

1. **📊 Market Price Browsing** — Explore available market and product price information.
2. **📂 Product Categories** — Browse products through category-based navigation.
3. **🔍 Product Details** — View detailed information about available products.
4. **🔐 Secure Authentication** — Sign up and sign in using email and password, with Google and GitHub authentication integration.
5. **📱 Responsive Design** — Enjoy a consistent browsing experience across mobile, tablet, and desktop devices.
